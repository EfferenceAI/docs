The Efference SDK is the host-side C++ library for the **Efference M1** sensor.
A single `ef::Device` handle exposes everything the device can do:

- **Data plane** — live video + IMU with a ZED-style `open` / `grab` /
  `retrieve` loop, over USB or WiFi/UDP, plus MCAP file replay.
- **Control plane** — identity, configuration, health checks, WiFi
  provisioning, on-device recording, uploads, and firmware updates, over USB
  or Bluetooth LE.

```cpp
#include <ef/Device.hpp>

ef::Device dev;
if (dev.open() != ef::ERROR_CODE::SUCCESS) return 1;

ef::Mat image;
ef::SensorsData sensors;
while (true) {
    if (dev.grab() == ef::ERROR_CODE::SUCCESS) {
        dev.retrieve_image(image, ef::VIEW::RGBA);
        dev.retrieve_imu(sensors);
    }
}
```

## Transports

| Transport | Control | Video + IMU | How |
|---|---|---|---|
| **USB** | ✓ | ✓ live isochronous | default; `open()` |
| **Bluetooth LE** | ✓ (password-gated) | — control only | `InitParameters::input_type = STREAM` |
| **WiFi / UDP** | via BLE | ✓ live UDP | BLE + `InitParameters::udp_host` |
| **MCAP replay** | — | ✓ from file | `InitParameters::input_type = MCAP` |

## Requirements

Linux (x86_64 or Jetson/arm64) · C++17 · CMake ≥ 3.16 · `libusb-1.0`.
FFmpeg, SDL2, and GLib are optional (H.264/H.265 decode, the live viewer, and
Bluetooth LE respectively).
