---
title: "efference-viewer"
description: "View live video and IMU data"
---

`efference-viewer` displays decoded video, frame count, acceleration, and
angular velocity.

```
efference-viewer [--codec raw|h264|h264hq|h265|h265hq]
                 [--ble MAC] [--password PW] [--udp HOST[:PORT]]
                 [--flip on|off|auto]
```

- **Wired:** run without connection flags; USB is the default.
- **Wireless:** pass `--ble <MAC> --udp <linux-host-ip>`.
- **Quit:** press `Q` or `Esc`, close the window, or press Ctrl-C.

Requires the SDK built with OpenCV + FFmpeg (installed by the first-time
`./build.sh --deps` command). CMake skips this tool if either is missing.

For persistent USB corruption, confirm that `ef info` reports a SuperSpeed
connection.
