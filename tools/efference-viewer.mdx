---
title: "efference-viewer — Live Viewer"
description: "Decoded video window with live IMU readout"
---

`efference-viewer` opens an OpenCV window with the decoded stream. A status
bar above the frame shows the live frame counter and current IMU values
(accel m/s², gyro rad/s), echoed to the console once per second.

```
efference-viewer [--codec raw|h264|h264hq|h265|h265hq]
                 [--ble MAC] [--password PW] [--udp HOST[:PORT]]
                 [--flip on|off|auto]
```

- **Wired:** just run it — USB is the default.
- **Wireless:** `efference-viewer --ble AA:BB:CC:DD:EE:FF --udp <your-ip>` —
  BLE carries control, the device pushes video to your IP over WiFi/UDP.
- **Quit:** `Q`, `Esc`, window close, or Ctrl-C.

Requires the SDK built with OpenCV + FFmpeg (both installed by `./build.sh`).
CMake skips this tool if either is missing.

<Note>
Brief glitches after packet loss on UDP are expected — the viewer requests a
fresh keyframe (PLI) and the image heals within a few frames. Persistent
corruption on USB usually means insufficient bandwidth: check that the device
enumerated at SuperSpeed (`ef info`).
</Note>
