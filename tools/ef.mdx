---
title: "ef"
description: "Control and inspect an Efference M1"
---

`ef` controls the M1 over USB by default. Add `--ble <MAC>` for Bluetooth LE
(BLE).

```
ef [--ble <MAC>] [--device <id>] [--password <pw>] [--udp <host[:port]>] [--verbose] <command> [args]
```

## Global flags

| Flag | Meaning |
|---|---|
| `--ble <MAC>` | connect over Bluetooth LE instead of USB |
| `--device <id>` | pick one of several USB devices |
| `--password <pw>` | BLE control password (factory default `123456`) |
| `--udp <host[:port]>` | with `--ble`: device streams to this host over WiFi/UDP |
| `--verbose` | print control traffic |

## Commands

### Discovery & identity

```sh
ef list [--scan-ble]      # discover devices
ef info                   # identity snapshot: serial, fw, camera, IMU, WiFi
ef state                  # current DEVICE_STATE
ef config                 # enabled capture modes + current configuration
ef config set 1920 1200 30 h265   # persist a capture config (idle only)
```

### Health

```sh
ef health [--deep]        # on-device sweep; --deep adds the stress tier
```

### Recording

```sh
ef record start [name] [--location LAT,LON[,ALT]]
                          # device-local recording (survives disconnect);
                          # --location overrides just this recording
ef record stop
ef record status [name]
ef record list
ef record delete <name>
ef download <name> [dest] # pull over USB/BLE (default <name>.mcap)
ef storage                # free/total on the recording store
```

### Upload

```sh
ef upload <name> <presigned-url>   # device uploads over WiFi
ef stop-upload <name>
```

### Update

```sh
ef check-update
ef update [url|firmware.eff]       # a local .eff sideloads over the wire
ef abort-update
```

### WiFi & misc

```sh
ef wifi add <ssid> <psk> [country]
ef wifi remove <ssid> | select <ssid> | status
ef wifi list                       # saved networks (marks the connected one)
ef set-password <new>              # rekey BLE password (over USB)
ef set-password <old> <new>        # rekey over BLE
ef sync-time                       # set the device clock from the host
ef time                            # read the device wall clock
ef location                        # read the device's current location
ef location set <lat> <lon> [alt]  # persist the device location
ef reboot
```
