## Requirements

- Linux (Ubuntu 22.04/24.04, Debian, or JetPack on NVIDIA Jetson — any
  apt-based distro installs dependencies automatically)
- A C++17 compiler, CMake ≥ 3.16, pkg-config
- `libusb-1.0` — the only required dependency

Optional features pull in extra packages, all installed automatically by the
build script:

| Feature | Packages |
|---|---|
| H.264/H.265 decode in `retrieve_image()` | `libavcodec-dev libavutil-dev libswscale-dev` |
| Bluetooth LE control | `libglib2.0-dev libssl-dev` |
| `efference-viewer` + the OpenCV examples | `libopencv-dev` + FFmpeg |

## Build

<Steps>
  <Step title="Clone">
    ```sh
    git clone https://github.com/efferenceai/efference.git
    cd efference
    ```
  </Step>
  <Step title="Build">
    ```sh
    ./build.sh
    ```
    The script installs the build dependencies (apt), installs the USB udev
    rule, then configures and builds with CMake. Binaries land in
    `sdk/linux/build/`.
  </Step>
  <Step title="Verify">
    Plug in the M1 over USB and run:
    ```sh
    ./sdk/linux/build/ef info
    ```
    You should see the device's serial, firmware version, camera modes, and
    IMU parameters.
  </Step>
</Steps>

<Note>
The build installs a udev rule at `/etc/udev/rules.d/51-efference.rules` so
non-root users can open the device. If you skip it (`EF_SKIP_UDEV=1
./build.sh`), running as a regular user fails with
`INSUFFICIENT_PERMISSIONS`. Re-plug the device after the rule is installed.
</Note>

## Plain CMake

The Linux SDK is a self-contained CMake project:

```sh
cd sdk/linux
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

Optional pieces degrade gracefully: without FFmpeg only the RAW/NV12 path is
available; without GLib/OpenSSL the SDK is USB-only; without OpenCV the
viewer and the OpenCV examples are skipped. CMake prints what was enabled at
configure time.

## Linking against the SDK

Add the SDK as a subdirectory, or install it and link `ef`:

```cmake
add_subdirectory(efference/sdk/linux)
target_link_libraries(my_app PRIVATE ef::ef)
```

```cpp
#include <ef/Device.hpp>
```
