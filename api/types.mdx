## Mat

An owned image buffer filled by `retrieve_image()`. The fields are private —
the SDK is the sole producer — and consumers read through accessors:

| Accessor | Returns | Meaning |
|---|---|---|
| `getPtr()` | `uint8_t*` | raw pixel bytes (owning buffer) |
| `getFrameId()` | `uint32_t` | monotonic frame counter |
| `getTimestamp()` | `Timestamp` | capture time, device clock |
| `getWidth()` / `getHeight()` / `getResolution()` | `int` / `Resolution` | frame geometry |
| `getDataType()` | `MAT_TYPE` | element layout (`U8_C1/C3/C4`, `NV12`) |
| `getView()` | `VIEW` | the view it was retrieved as |
| `getStep()` | `int` | bytes per row (first plane) |
| `getSizeInBytes()` | `size_t` | total buffer size |
| `isInit()` | `bool` | whether a buffer is allocated |
| `getMemoryType()` | `MEM` | where the buffer lives |

Copies and assignment are deep. `alloc(int, int, MAT_TYPE, MEM = MEM::CPU)`
and `free()` manage a standalone buffer, and
`copyTo(Mat&, MEM = MEM::CPU) const` deep-copies pixels. `getPtr()` also takes
an optional `MEM`. `MEM::GPU` is not supported and returns `UNSUPPORTED`.

## ImuSample / SensorsData

```cpp
struct ImuSample {
    Timestamp timestamp;                 // device clock
    uint64_t  sequence;                  // monotonic; gaps = wire loss
    float     acceleration[3];           // m/s^2
    float     angular_velocity[3];       // rad/s
    float     temperature_c;
};

struct SensorsData {                     // filled by retrieve_imu()
    std::vector<ImuSample> samples;      // all samples since the last drain
    uint64_t     dropped;                // host ring overruns
    MOTION_STATE motion_state;           // STATIC / MOVING / FALLING
};
```

## Timestamp

Nanoseconds since epoch, held in the public field `data_ns`, with unit
accessors: `nanoseconds()`, `microseconds()`, `milliseconds()`, `seconds()`.

## DeviceInformation

Cached at `open()`, returned by `get_device_information()`:

```cpp
struct DeviceInformation {
    std::string  serial;             // full serial (may be non-numeric)
    unsigned int serial_number;      // numeric form; 0 when not numeric
    MODEL        model;
    unsigned int firmware_version;   // monotonic int used for anti-rollback
    std::string  firmware_version_str;   // human-readable "XX.XX.XX"
    INPUT_TYPE   input_type;
    CameraConfiguration  camera_configuration;    // resolution, fps, codec, calibration
    SensorsConfiguration sensors_configuration;   // IMU params + extrinsics
    WirelessConfiguration wireless;               // WiFi/BT state
    Capabilities         capabilities;            // enabled modes + codecs
};
```

- `CameraConfiguration::calibration` — a `CalibrationParameters`: the
  double-sphere intrinsics (`fx fy cx cy xi alpha`), the `model`, the `width`
  and `height` they were calibrated at, plus two fields that change device
  behavior rather than describe it — `rectify` (default `false`; when set the
  device undistorts frames itself, so recordings ship rectilinear instead of
  raw fisheye) and `fov_scale` (default `1.0`; below 1 is wider, above 1
  zooms).
- `SensorsConfiguration` — `accelerometer` and `gyroscope` (each a
  `SensorParameters`: `type`, `unit`, `sampling_rate`, `range`,
  `noise_density`, `bias_random_walk`, `tau`, `state`), the 4×4
  `camera_imu_transform` camera→IMU extrinsic, and the field-calibration
  read-back: `accel_bias`, `gyro_bias`, `accel_scale_misalign`,
  `gyro_scale_misalign`, and `time_offset_ns`.
- `WirelessConfiguration` — `wifi_mac_address`, `bt_mac_address`, `bt_paired`,
  `wifi_connected`, `wifi_ssid`, `wifi_ip_address`, `wifi_rssi`,
  `internet_reachable`, `wifi_state`, `wifi_link_speed`, `wifi_freq_mhz`,
  `wifi_security`, and `saved_networks`.
- `Capabilities` — `modes` (the selectable menu; values outside it are
  rejected at `open()`) and `codecs`. Each `SupportedMode` carries
  `resolution`, `fps`, and `binning` (`"none"` or `"2x2"`, how the mode
  derives from the full sensor).

## Status structs

```cpp
struct HealthStatus {
    CAMERA_STATE camera;             // live availability
    SENSOR_STATE imu;
    bool         passed;             // last sweep: no probe failed
    bool         deep;               // stress tier included
    std::vector<HealthCheck> checks; // per-probe {name, passed, detail}
    Timestamp    timestamp;
};

struct RecordingStatus {
    std::string      name;
    RECORDING_TARGET target;
    bool     recording;
    uint64_t bytes, frames, duration_ms;
    uint64_t storage_free_bytes, storage_total_bytes;
    UPLOAD_STATE upload;             // + upload_bytes_sent / upload_bytes_total
    ERROR_CODE   last_error;
};

struct UpdateStatus {
    bool         active;
    UPDATE_STATE state;              // see UPDATE_STATE for all eight phases
    int          progress;           // 0–100, -1 indeterminate
    std::string  message;
    std::string  running_version;    // human-readable
    uint32_t     running_version_int, target_version_int;
    ERROR_CODE   last_error;
};
```

## DeviceProperties

One row of `get_device_list()`:

| Field | Meaning |
|---|---|
| `input_type` | `USB` or `STREAM` (BLE) |
| `device_id` | index for `InitParameters::device_id` |
| `serial` | USB descriptor serial |
| `ble_address` / `ble_name` | BLE identity (STREAM rows) |

## WifiNetwork

One access point from `scan_wifi_networks()`: `ssid`, `rssi` (dBm, higher is
stronger), and `secured` (WPA/WPA2/WPA3).

## ImuCalibrationParameters

Passed to `set_imu_calibration()`. The model is `a* = M·S·(x − b)`, with the
3×3 scale-misalignment folding `M` and `S` together, row-major, per sensor.
Every field defaults to the identity map, so a partially filled struct is safe.

`accel_bias`, `gyro_bias`, `accel_scale_misalign`, `gyro_scale_misalign`,
`accel_noise_density`, `gyro_noise_density`, `accel_bias_random_walk`,
`gyro_bias_random_walk`, `accel_tau`, `gyro_tau`, `imu_to_camera` (4×4), and
`time_offset_ns`.

## Location

`latitude`, `longitude`, `altitude`, `covariance_diag` — written into each
recording's `LocationFix` MCAP message.
