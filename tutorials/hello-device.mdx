The smallest possible program: open the device, print who it is, close.

```cpp
#include <cstdio>
#include <ef/Device.hpp>

using namespace ef;

int main() {
    Device dev;

    ERROR_CODE ec = dev.open();
    if (ec != ERROR_CODE::SUCCESS) {
        std::printf("open failed: %s\n", to_string(ec));
        return 1;
    }

    DeviceInformation info = dev.get_device_information();
    std::printf("model:    %s\n", to_string(info.model));
    std::printf("serial:   %s\n", info.serial.c_str());
    std::printf("firmware: %u\n", info.firmware_version);

    dev.close();
    return 0;
}
```

## Walkthrough

- `open()` with no arguments uses the defaults: USB transport, device 0,
  native resolution, H.265. It claims the device, caches its identity, syncs
  the clock, and starts capture.
- Every wire-touching call returns an `ERROR_CODE`; `to_string()` renders it
  for logs. The common first-run failures: `DEVICE_NOT_DETECTED` (cable/port)
  and `INSUFFICIENT_PERMISSIONS` (udev rule missing — see
  [Installation](/get-started/installation)).
- `get_device_information()` returns instantly from values cached at
  `open()`, so it is safe anywhere, including hot loops.

This example ships in the repo as `examples/wired/01_serial_number.cpp` and
builds automatically:

```sh
./sdk/linux/build/wired_01_serial_number
```
