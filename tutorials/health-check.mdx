title: "Tutorial 2 — Health Check"
description: "Run the diagnostic sweep and inspect per-probe results"
---

```cpp
#include <cstdio>
#include <ef/Device.hpp>

using namespace ef;

int main() {
    Device dev;
    if (dev.open() != ERROR_CODE::SUCCESS) return 1;

    HealthStatus health;
    ERROR_CODE ec = dev.health_check(health);   // blocks until the sweep completes
    if (ec != ERROR_CODE::SUCCESS) {
        std::printf("health check failed to run: %s\n", to_string(ec));
        return 1;
    }

    std::printf("overall: %s\n", health.passed ? "PASS" : "FAIL");
    std::printf("camera:  %s\n", to_string(health.camera));
    std::printf("imu:     %s\n", to_string(health.imu));

    for (const HealthCheck& c : health.checks)
        std::printf("  %-16s %-4s %s\n", c.name.c_str(),
                    c.passed ? "PASS" : "FAIL", c.detail.c_str());

    dev.close();
    return 0;
}
```

## Walkthrough

- `health_check(out)` runs the quick sweep; `health_check(out, true)` adds
  the ~2 minute stress tier (memory, CPU, thermals, and sensor sync) —
  worth running on newly received or suspect units.
- Distinguish the two failure modes: a non-`SUCCESS` return means the sweep
  *could not run* (transport problem); `health.passed == false` means it ran
  and a probe failed — look at `checks` for which.
- Results cache on the handle: `get_health_status()` re-reads the last sweep
  without touching the device.

Works identically over Bluetooth LE (control-only session — no `udp_host`
needed), which makes it the natural first wireless smoke test. Ships as
`examples/wired/02_health_check.cpp`.
